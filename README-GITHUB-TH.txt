MUDMEE MODERN — GitHub Pages
วิธีใช้งาน:
1) แตกไฟล์ ZIP นี้
2) อัปโหลด index.html และ .nojekyll ไปไว้ที่ระดับแรก (root) ของ GitHub Repository
3) กด Commit changes
4) เข้า Settings > Pages
5) เลือก Deploy from a branch, Branch: main, Folder: /(root) แล้ว Save
6) รอให้ GitHub Pages deploy เสร็จ แล้วเปิดลิงก์จากปุ่ม Visit site

หมายเหตุ: รูปสินค้าและโลโก้ฝังอยู่ใน index.html แล้ว ไม่ต้องอัปโหลดโฟลเดอร์รูปภาพแยก
